live on the device

Setup

Two apps, one connection, no fuss.

There's no cloud account to create and no server in between — your phone talks straight to your computer.

1

Install the host

A small app runs on your Mac or PC and quietly waits for your phone to say hello.

2

Install HotkeyPad

Open the app on your phone — it looks for a host over Bluetooth or your Wi‑Fi network automatically.

3

Build your deck

Drag apps, media controls, and shortcuts onto a grid. Swipe between pages, rename buttons, pick your own icons.

On the deck

Every button does one real thing.

No macros to script, no plugin marketplace to dig through — five kinds of button cover almost everything you'd reach for a shortcut key for.

Launch an app

Or a Steam game on Windows — pick it from what's already installed.

Control media

Play, pause, skip, and volume — for whatever's currently playing.

Run a shell command

One line, run instantly — for the script you already reach for.

Run a Shortcut

Trigger any macOS Shortcut by name, no scripting required.

Send a key combination

⌘⇧4, a mute toggle, whatever chord you'd otherwise have to remember.
